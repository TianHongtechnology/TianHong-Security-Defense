产品概览

一套纵深防御的终端防护体系

从内核到用户态、从行为到特征、从静态到动态的全链路防护，为 Windows 终端提供主动、实时、可决策的安全能力。

实时行为监控

内核 500ms 定时器持续采集全进程行为数据：内存操作、进程创建、网络连接、文件与注册表变更、COM 调用、ETW 事件，多维指标加权评分识别恶意行为。

主机入侵防御 HIPS

基于 TOML 规则的入侵防御系统，拦截文件、注册表、网络与进程操作；命中规则后弹窗等待用户决策，支持意图判断与 5 分钟决策缓存，避免误报骚扰。

注入防护 · 三层渐进

句柄层（ObRegisterCallbacks）剥离注入权限 → 线程层（PsSetCreateThreadNotifyRoutine）立即挂起 → 行为层异步告警，覆盖远程线程、APC、进程空心化、PoolParty 等手法。

MBR / 磁盘保护

独立 WDM 磁盘过滤驱动附加到物理磁盘设备栈，拦截启动区域（扇区 0–62，31KB）写入，保护 MBR 与 DBR 免遭引导扇区病毒与勒索软件破坏。

网络过滤防护

基于 Windows Filtering Platform（WFP）Callout 拦截 DNS / DoH 查询，切断 C2 通道；支持动态规则同步，可自定义网络通信策略。

静态特征扫描

三引擎协同：YARA 签名匹配 + ClamAV 商业病毒库（动态加载）+ LightGBM 机器学习模型（600 维 PE 特征双模型），支持归档遍历与批量扫描。

意图判断

根据 DesiredAccess 与 CreateDisposition 判定真实操作意图（写/删/重命名），避免误触发。注册表 DELETE/READ 直接阻止不弹窗。

决策缓存

同一进程 + 请求的决策缓存 5 分钟；进程退出时清理缓存，防止 PID 复用导致错误决策继承。

PhysicalDrive 原始写全拦截 System32 exe 投放 drivers sys 投放 hosts 篡改 启动文件夹 计划任务目录 SEF_ALL_BLOCKED 全拦截 SEF_UNSIGNED_BLOCKED 未签名拦截 SEF_NOT_SYSTEM_BLOCKED 非系统拦截

用户决策流程（弹窗闭环）

1. 操作请求到达 FileFilterMatchRules / DetectRegPath 规则引擎 2. 命中规则 → AskClientForResponse 同步弹窗（35s 超时） 3. 用户选择 允许 → 放行并缓存；拒绝/超时 → STATUS_ACCESS_DENIED 4. 网络过滤 Paging IO 场景 → 勒索诱捕规则直接拦截
热更新：支持运行时添加 / 删除 / 清除规则，规则变更无需重启驱动或系统。

64 层递归深度上限防栈溢出；完整支持 UTF-16LE（PowerShell 编码）；超过 20MB 文件跳过分析防 OOM。

使用边界与免责声明

严禁在实体机上运行本程序。 内核驱动级别的挂钩、过滤与进程干预操作可能导致系统蓝屏、数据丢失或不可恢复的系统损坏。 请务必使用虚拟机（VMware / VirtualBox / Hyper-V 等）在隔离环境中进行测试。

敏感项一 · 加密密钥

PublicDefine.h 中的 XOR 加密密钥为硬编码，可被逆向获取——正式部署前请更换或移至配置文件。

敏感项二 · 自签名证书

Resources/BinaryFiles/root.spc 自签名根证书可被利用来签名恶意程序——请替换为正式证书或删除。

敏感项三 · 固定端口

Socket 通信绑定 localhost 固定端口 12345–12347——生产环境请更改端口号。
